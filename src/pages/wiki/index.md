# Engineering Wiki

## Lead Software Engineer | Application, platform, and delivery engineering

I am a Lead Software Engineer at State Farm. I work across Java and Spring
Boot services, GraphQL APIs, Amazon Web Services (AWS), Red Hat OpenShift
Service on AWS (ROSA), Kubernetes, Argo CD GitOps, secure delivery, and
production observability.

This wiki explains how I think about building and operating software. It also
covers how I use Dynatrace, Slack, Jira, Confluence, Claude, and Codex in the
engineering workflow. The examples are intentionally general so they do not
expose employer-specific architecture or confidential information.

## A useful definition of done

A system is not finished when it runs on a developer laptop. It is finished
when the team can deploy it safely, observe it in production, recover it under
pressure, and explain how it works to the next engineer.
